About AEGIS

Adaptive Edge Guardian for Identity and Sensors

AEGIS is a capstone prototype designed to demonstrate identity-aware IoT telemetry, local risk analysis, and secure device monitoring without reliance on opaque cloud analytics.

Each IoT node is treated as a first-class identity with expected behavioral ranges. Telemetry is evaluated continuously, and deviations are surfaced as explainable risk signals.

Pipeline highlights

  • Identity-first IoT telemetry model
  • MQTT over TLS via HiveMQ Cloud
  • Local Flask gateway for data normalization
  • Real-time charts and health indicators
  • Rule-based risk scoring for explainability

Risk engine design

  • Explicit environmental assumptions
  • Human-readable thresholds
  • No black-box decisions
  • Designed for SOC and audit contexts

Additional notes

  • The camera stream never leaves the local network
  • Charts freeze on telemetry loss to preserve context
  • The risk engine can be deployed at the edge
  • Architecture supports future IAM integration
  • Designed for capstone defense and extension
